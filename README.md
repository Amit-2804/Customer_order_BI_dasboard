# 🛒 Customer Orders Analytics Dashboard

An interactive Power BI dashboard tracking sales revenue, order fulfillment, and customer purchasing patterns to drive actionable business insights.

---

## 📌 Project Overview
This project visualizes transactional customer order data to evaluate core sales KPIs, identify high-value customer segments, and analyze product performance across regions.

---

## 🎯 Key Visuals & Insights
* **Sales & Revenue KPIs:** High-level metrics tracking Total Sales, Total Orders, Average Order Value (AOV), and overall Profit.
* **Customer Purchasing Patterns:** Segmentation based on order volume, repeat purchase behavior, and total spend.
* **Product & Category Performance:** Breakdown of top-performing product categories and item-level contribution.
* **Order Status & Fulfillment:** Analysis of order completion, fulfillment stages, and return rates.
* **Geographical Trends:** Regional distribution of sales volume and active customer markets.

---

## 🛠️ Tools & Technologies
* **BI Tool:** Microsoft Power BI
* **Data Transformation:** Power Query (ETL, cleaning, type conversions)
* **Data Modeling:** Dimensional modeling / Star schema relationships
* **Calculations:** DAX measures and calculated columns
